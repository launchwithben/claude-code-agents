## Tokens and themes
1. Colours, spacing and radii come from the design tokens, never raw hex or pixel values. (docs/design-system.md)
2. Every screen works in light AND dark. Screenshot both before handback.

## Components
3. Search existing components first and reuse; build a new one only when none fits. (src/components)
4. Icons come from the existing icon set. Do not add a second one.

## Look
5. Example: one dominant call to action per screen; secondary actions are visibly quieter.
6. Example: copy is plain and specific. No filler superlatives.
